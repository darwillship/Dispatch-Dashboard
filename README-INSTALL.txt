DISPATCH DASHBOARD v1.5.0 — DRIVER BOARD

NEW
- Driver-centered dispatch board.
- Every driver in the Supabase drivers table gets a card, even with zero routes.
- Unassigned Routes card at the top.
- Routes appear inside the assigned driver's card.
- Drag a route to another driver's card to reassign it.
- Drag a route into Unassigned Routes to unassign it.
- Edit, Delete and quick Status controls remain on each route.
- Route Title remains removed; pickup → delivery is used automatically.
- Existing Create Route, locations and vehicle dropdown remain.

NOTE
Route reassignment is saved to Supabase.
Custom visual ordering is still remembered by the current browser. A future database sort_order field can make ordering identical on every computer.
