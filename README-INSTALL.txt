DISPATCH DASHBOARD v1.7.0 — DAILY ARCHIVE + HISTORY

- Active board shows only routes scheduled for today's local date.
- When the day changes, yesterday's cards automatically disappear from the active board.
- Routes are NOT deleted. They remain in Supabase.
- Pending, Assigned, In Progress and Completed statuses are preserved.
- New Route History button opens yesterday by default.
- Select any previous date to review saved routes.
- Existing active-driver cards, Create/Edit/Delete, status colors, drag/reassign, drivers/messengers, locations and vehicle UI remain.

The route's scheduled_at date controls which day it appears on.
